## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or bun

### Installation

```sh
# Clone the repository
git clone https://github.com/imtushaarr/ai-portfolio.git

# Navigate to project directory
cd ai-portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

The portfolio will be available at `http://localhost:8080`

## 📦 Build & Deployment

### Development
```sh
npm run dev
```

### Production Build
```sh
npm run build
```

### Preview Production Build
```sh
npm run preview
```

### Testing
```sh
npm test
npm test:watch  # Watch mode
```

### Linting
```sh
npm run lint
```

## 🌐 Deployment Options

The portfolio can be deployed on various platforms:

- **Vercel** - Zero-config deployment with automatic HTTPS
- **Netlify** - Easy drag-and-drop or Git-based deployment
- **GitHub Pages** - Free static hosting
- **AWS S3 + CloudFront** - Scalable cloud hosting
- **DigitalOcean** - Affordable cloud hosting

To deploy:
1. Build the project: `npm run build`
2. Deploy the `dist` folder to your hosting service

## 📚 Project Stack

- **Frontend Framework**: React 18
- **Build Tool**: Vite 5
- **Language**: TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Routing**: React Router v6
- **Form Handling**: React Hook Form
- **UI Components**: shadcn-ui (Radix UI + Tailwind)
- **HTTP Client**: TanStack React Query
- **Charts**: Recharts
- **Testing**: Vitest + React Testing Library
- **Linting**: ESLint
- **Icons**: Lucide React
- **Notifications**: Sonner + Radix Toast
